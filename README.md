In this software, you can set up stockpile quantities for various goods and daily rental rates. You can also record customer information. You can use it on a daily basis to track items rented out and returned; the software will automatically calculate the rent generated during the rental period and generate a report. You can also view each customer's current rental status, daily rental income, and the rent generated from returned items. If the data entered during a particular transaction violates the physical reality of inventory, the software will immediately report an error and refuse to record the transaction. The software supports exporting detailed rental reports for individual customers.
